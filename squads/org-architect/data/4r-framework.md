# The 4R Framework — Reference

Source: Josh Bersin's **4R** model for closing capability gaps. Used by `fourr-advisor` and
referenced by `org-architect-chief`. The core idea: **recruiting is the residual, not the reflex.**

## The four R's (evaluate in order)

1. **Redesign** — Can the work be re-scoped, automated or recombined so existing roles cover it?
   Cheapest and fastest when it applies; often the most overlooked.
2. **Reskill** — Who is one focused learning track away from the capability? Internal reskilling is
   frequently cheaper and faster than backfilling, and it builds retention. Route to `academy`.
3. **Retain** — Does the capability already exist internally but at flight risk? Secure it first —
   losing it converts a Retain into a premium Recruit. Route to `performa` / `pulse`.
4. **Recruit** — The **residual net-new** need after the first three. Size it last; route to `talent-compass`.

## How to apply

1. **Size the gap in skills, not heads.** "We need ML deployment + monitoring," not "we need 3 people."
   Headcount is an output of the analysis, not its input.
2. **Estimate coverage per path.** What % of the gap does each R realistically close?
3. **Quantify cost, time-to-capability and risk** for each path.
4. **Recommend a blend/sequence.** Usually: retain now → redesign/reskill in parallel → recruit the residual.

## Worked logic

> Leadership asks for 3 reqs. 4R reveals: redesign covers 30% (re-scope a senior role), reskill covers 30%
> (2 analysts, ~10 weeks via academy), retain is urgent (1 flight-risk engineer holds the core skill), and
> the residual recruit need is ~1 hire — not 3. The reflex would have over-hired and under-retained.

## Connections in the platform

- **Reskill → `academy`** (learning tracks to close the gap)
- **Retain → `performa` / `pulse`** (growth, recognition, engagement)
- **Recruit → `talent-compass`** (the residual role becomes a vacancy)
- **Redesign → `role-designer` / `org-modeler`** (re-scope roles / structure)

## Anti-patterns

- Treating every capability gap as a hiring problem.
- Jumping to Recruit before the first three R's.
- Ignoring flight risk on a scarce, needed capability.
- Sizing in headcount instead of skills.
