# Checklist — Completude Documental (QG-JE-002)

Aplicado pelo `document-intake-validator` a todo caso antes da análise de mérito.

## Aplicação do Checklist

- [ ] Tipo de demanda identificado e checklist correspondente carregado (data/document-checklists.yaml).
- [ ] Cada documento obrigatório classificado: presente, ausente ou inconsistente.
- [ ] Documentos ilegíveis tratados como ausentes até saneamento.
- [ ] Score documental calculado e comparado ao mínimo do tipo de demanda.

## Classificação do Caso

- [ ] Caso classificado: apto, pendente de saneamento ou bloqueado.
- [ ] Justificativa objetiva registrada para a classificação.
- [ ] Cada item rastreável ao documento verificado.

## Pendências

- [ ] Toda pendência indica documento específico, setor responsável e impacto.
- [ ] Pendências comunicadas ao setor via comunicação humanizada.
- [ ] Prazo de retorno definido e monitorado.

## Segurança

- [ ] Nenhum caso de risco alto/crítico liberado para judicialização sem revisão jurídica.
- [ ] Documentos com dados sensíveis sinalizados ao auditor LGPD.
