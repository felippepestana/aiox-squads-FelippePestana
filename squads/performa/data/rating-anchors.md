# Rating Anchors (1–5)

A shared, behaviorally-anchored scale so a "3" means the same thing across raters. Every rating must cite a recent, concrete example — otherwise the competency is **insufficient evidence**, not a default 3.

| Rating | Label | Behavioral anchor |
|--------|-------|-------------------|
| 1 | Below | Consistently misses expectations on this competency; impact is negative or requires rework. |
| 2 | Developing | Partially meets; needs guidance/support; inconsistent results. |
| 3 | Meets | Reliably meets expectations for the level; solid, independent performance. |
| 4 | Exceeds | Regularly goes beyond expectations; raises the bar for peers. |
| 5 | Outstanding | Exceptional, sustained impact well beyond the level; a model for others. |

## Rules
- **Anchor to the level.** A "meets" for a senior is a higher bar than for a junior; rate against the role's expectations.
- **Evidence per rating.** No recent example → mark *insufficient evidence* (calibration-gate vetoes empty 3s).
- **Whole period.** Cover the full window, not just the last weeks (recency bias).
- **No halo.** Strength in one competency doesn't lift the others; rate each on its own evidence.
- **Personality is weight 0.** Style/likeability never moves the number — it's context for development only.

## Calibration
Distributions are normalized across raters (leniency/severity) and audited for demographic skew before any rating is shared. See `checklists/calibration-fairness-gate.md`.
