# Enneagram Reference (development lens only — weight 0, with guardrails)

The Enneagram is used in talent-compass **only as a developmental lens** — for self-awareness, coaching and onboarding, with consent. It has **low predictive validity for selection** and must **never** be used to screen, score, or rank candidates. It carries weight 0 in any hiring decision.

## The nine types (developmental sketch)

| Type | Core motivation | Growth edge |
|------|-----------------|-------------|
| 1 — Reformer | Integrity, correctness | Ease up on self-criticism; accept "good enough" |
| 2 — Helper | Being needed, connection | Own and voice their own needs |
| 3 — Achiever | Success, value through results | Authentic self vs. performed image; slow down |
| 4 — Individualist | Identity, authenticity | Stability; not over-identifying with feelings |
| 5 — Investigator | Competence, understanding | Engage and share before fully "ready" |
| 6 — Loyalist | Security, certainty | Trust own judgment; manage anticipatory anxiety |
| 7 — Enthusiast | Stimulation, options | Focus and follow-through; sit with discomfort |
| 8 — Challenger | Control, protection | Vulnerability; tempering intensity |
| 9 — Peacemaker | Harmony, comfort | Assert priorities; avoid conflict-avoidance |

## How to use it (and how not to)

**Do:**
- Offer it for self-awareness, coaching conversations and onboarding **with the person's consent**.
- Use self-reported type, framed as a lens for growth.
- Keep it in a clearly labeled **context** section, weight 0.

**Don't:**
- Use it to screen, score, rank, or reject candidates.
- Type someone from the outside and treat it as fact.
- Present it as predictive of job performance.

## Ethical guardrails
- State the instrument's limits every time it appears.
- Require informed consent; treat as sensitive personal data.
- Never let it influence the scorecard or the recommendation.

> One line for every output that mentions the Enneagram: *"This is a development lens, shared with consent, with weight 0 in the hiring decision."*
