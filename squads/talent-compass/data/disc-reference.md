# DISC Reference (context only — weight 0)

DISC is used in talent-compass **only as context** to tailor communication, question phrasing and onboarding. It is **never** a score, a filter, or a ranking factor. Read tendencies, not destinies; flag low confidence on thin evidence.

## The four styles (tendencies)

| Style | Drive | Tends to look like | Works best when |
|-------|-------|--------------------|-----------------|
| **D — Dominance** | Results, control | Direct, fast, decisive, impatient with detail | Given autonomy, clear goals, bottom-line first |
| **I — Influence** | People, recognition | Enthusiastic, persuasive, relational, optimistic | Given interaction, visibility, room to ideate |
| **S — Steadiness** | Stability, harmony | Patient, consistent, supportive, dislikes abrupt change | Given stability, clear expectations, time to adapt |
| **C — Conscientiousness** | Accuracy, quality | Analytical, precise, careful, risk-aware | Given data, standards, time to do it right |

Most people are a blend (e.g., high-D/C, high-I/S). Describe the blend, not a single letter.

## How to use it (and how not to)

**Do:**
- Adjust how you *frame* questions (give a high-C candidate concrete detail; give a high-I candidate space to talk).
- Inform onboarding and how a manager should communicate with the person.
- Note communication tendencies in the report's **context** section, clearly labeled weight 0.

**Don't:**
- Add it to the score or use it to rank candidates.
- Say "we need a high-D for this role" as a selection criterion.
- Treat a style as a fixed trait or a performance predictor.

## Ethical guardrails
- DISC has limited predictive validity for job performance — do not present it as predictive.
- Avoid deterministic language ("D types always…"). Use "tends to", "leans", "in this sample".
- Require consent for any formal assessment; respect data sensitivity.

> One line for every report that mentions DISC: *"Behavioral style is context for how to work with this person — it carries weight 0 in the hiring decision."*
