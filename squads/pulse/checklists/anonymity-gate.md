# Anonymity Gate Checklist

> Run by **anonymity-gate** before any result cut is published or shared. The verdict is **PASS** or **VETO**.
> No cut leaves the room below the minimum group size.

## 1. Minimum group size

- [ ] Every reported segment is **≥ minimum group size**.
- [ ] No "interesting but tiny" cut is included as an exception.

## 2. Re-identification

- [ ] No demographic cross-cut produces a small cell.
- [ ] Smallest cross-cut (not just the total) checked.
- [ ] Where cells are small, a coarser safe aggregation is used instead.

## 3. Quotes

- [ ] No quote includes a name, a unique role, or an identifying project.
- [ ] Quotes that can't be anonymized are summarized, not published.

## 4. Purpose & scope

- [ ] Data used only for the listening/action purpose.
- [ ] No behavioral/personality data used as a selection or pay filter.

---

**Verdict:**

- **PASS** — all items clear → cleared for a human to publish.
- **VETO** — any item fails → return findings + safe alternative; re-aggregate and re-audit before publishing.
