# Sentiment Analysis Methodology (reference)

> How the sentiment-analyst turns open responses into themes and sentiment without exposing anyone.

## Codificação temática

1. **Leitura aberta:** passar por todas as respostas para capturar o espectro.
2. **Códigos:** agrupar trechos em códigos recorrentes (ex.: "carga", "reconhecimento", "ferramentas").
3. **Temas:** consolidar códigos em poucos temas com peso (saliência) e sentimento.
4. **Citações:** anexar 1 citação representativa por tema — **sempre anonimizada**.

## Sentimento

- Classificar por tema: positivo / misto / negativo (não só polaridade global).
- O sentimento dá direção; o **peso** (quantas pessoas) dá prioridade.

## eNPS + temas

- Reportar o eNPS e, ao lado, os **temas dos detratores** e dos **promotores**.
- O número é o sintoma; os temas são a causa acionável.

## Salvaguardas

- **Citações anônimas:** remover nomes, projetos específicos, papéis únicos. Se não dá para anonimizar, **resumir** em vez de citar.
- **Cortes seguros:** só reportar segmentos ≥ tamanho mínimo de grupo.
- **Sem reidentificação:** nada de cruzar demografias até virar célula pequena.

## Anti-erros

- Reduzir tudo a uma média.
- Citar literalmente algo que identifica a pessoa.
- Reportar um corte pequeno "porque é interessante".
