# Anonymity & Ethics (reference)

> Listening only works if the people who speak up are protected. This grounds the anonymity-gate.

## Tamanho mínimo de grupo

- Nenhum corte é reportado abaixo de um **tamanho mínimo de grupo** (ex.: 5). Abaixo disso, respostas viram identificáveis.
- O mínimo é definido **no desenho** e **reforçado no gate** antes de publicar.

## Risco de reidentificação

- Combinar demografias (área × cargo × gênero × tempo de casa) cria **células pequenas** que reidentificam mesmo com n agregado "ok".
- Regra: ao cruzar dimensões, checar o **menor cruzamento**, não só o total.
- Quando o cruzamento é pequeno → **agregar mais grosso** (ex.: só por área).

## Citações

- Citações ilustram, **nunca expõem**. Remover nomes, projetos, papéis únicos.
- Se não dá para anonimizar uma citação → **resumir** o ponto.

## Consentimento & finalidade

- Comunicar claramente o propósito da escuta e como o anonimato é protegido.
- Usar os dados só para o fim de escuta/ação; **comportamento é contexto, nunca filtro** de pay/seleção.

## Gate (PASS/VETO)

O `anonymity-gate` **VETA** publicação quando:

- [ ] Algum corte está abaixo do tamanho mínimo de grupo.
- [ ] Um cruzamento gera célula pequena (reidentificação).
- [ ] Uma citação pode identificar o respondente.

Corrigido (reagregar / resumir) → **PASS**. Só então um humano publica.
