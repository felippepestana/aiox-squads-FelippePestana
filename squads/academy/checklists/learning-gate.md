# Checklist: Learning Quality Gate (academy)

**Executor:** learning-gate (T3)
**Quando:** Antes de publicar QUALQUER trilha, curso ou certificação
**Veredito:** PASS (sem achados) ou VETO (com remediação). Nunca "PASS com ressalva" diante de erro de conteúdo ou objetivo não mensurável.

> Princípio: uma trilha bonita que não ensina é desperdício; uma que dissemina erro é dano em escala. Este gate protege ambos.

---

## 1. Objetivos Mensuráveis

- [ ] Todo objetivo tem **critério observável** (verbo + condição + critério)
- [ ] Cada competência é **observável no trabalho** (não traço de personalidade)
- [ ] O gap original está **rastreado** (fonte: performa/org-architect/insights)

**VETO se:** algum objetivo não é mensurável.

## 2. Verificação de SME (conteúdo crítico)

- [ ] Conteúdo de domínio crítico (jurídico, técnico, médico, financeiro, compliance) **identificado**
- [ ] Todas as afirmações `requer_SME` foram **verificadas por especialista**
- [ ] Nenhuma afirmação crítica apresentada como autoritativa sem revisão

**VETO se:** conteúdo crítico sem verificação de SME.

## 3. Foco em Aplicação (não vaidade)

- [ ] A avaliação mede **aplicação no trabalho** (Kirkpatrick nível 3+) onde o objetivo exige
- [ ] Não certifica por **conclusão/satisfação** apenas (Kirkpatrick 1-2)
- [ ] Itens alinhados ao **nível de Bloom** do objetivo (não abaixo)
- [ ] Certificação (se houver) tem **critério observável + limiar explícito**

**VETO se:** avaliação mede só conclusão num objetivo de aplicação.

## 4. Design 70-20-10

- [ ] Blend explícito: experiencial (70), social (20), formal (10)
- [ ] Pelo menos um **ponto de aplicação no trabalho** por competência
- [ ] Tempo **realista** para a jornada (cabe na semana)
- [ ] Spaced learning (não maratona única)

**ALERT se:** trilha 100% formal ou tempo irreal (replaneje; não bloqueia sozinho).

## 5. Acessibilidade

- [ ] Conteúdo essencial tem **canal alternativo** (vídeo → transcrição; imagem → texto alternativo)
- [ ] Legibilidade adequada (linguagem clara, estrutura navegável)
- [ ] WCAG básico respeitado

**VETO se:** canal único essencial sem alternativa.

## 6. Rastreabilidade (Audit Trail 100%)

- [ ] Fonte do gap registrada
- [ ] Objetivos e níveis de proficiência documentados
- [ ] Flags de SME e seu status registrados
- [ ] Mapeamento Kirkpatrick documentado
- [ ] Timestamp + user em cada etapa

**VETO se:** audit trail incompleto.

---

## Condição de PASS (todas obrigatórias)

✅ Objetivos mensuráveis · ✅ SME verificado (crítico) · ✅ Avaliação de aplicação ·
✅ 70-20-10 com ponto de aplicação · ✅ Acessível · ✅ Audit trail 100%

## Condição de VETO (qualquer uma bloqueia)

⛔ Objetivo não mensurável · ⛔ Conteúdo crítico sem SME · ⛔ Avaliação só de conclusão ·
⛔ Barreira de acessibilidade · ⛔ Trilha incompleta

**No bypass.** VETO retorna razão + remediação + reapresentação.
