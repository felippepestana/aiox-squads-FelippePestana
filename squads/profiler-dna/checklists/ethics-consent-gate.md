# Ethics & Consent Gate — Checklist

Owner: **ethics-gate** (Tier 3). **Mandatory** before any profile or fit report is delivered. Has **veto power**.

## A. Consent (blocking)
- [ ] Informed consent to profile is present and on record.
- [ ] The stated purpose is clear, and the profile is not being reused beyond it.

## B. Anti-stereotype language (blocking)
- [ ] No deterministic "type always" / "these people are" language.
- [ ] Tendencies and ranges used, with evidence cited.
- [ ] Confidence is stated; thin samples are labeled low confidence.

## C. Weight-zero framing (blocking)
- [ ] The profile is explicitly framed as **context, weight 0**.
- [ ] It is NOT being used (or presented) as a selection/promotion/pay factor.
- [ ] Fit reads are labeled **advisory**, not gates.

## D. No clinical overreach (blocking)
- [ ] No diagnosis, mental-health labels, or clinical claims.

## E. No protected-attribute proxy (blocking)
- [ ] Style/trait reads are not standing in for age, gender, race, religion, disability, etc.

## Verdict
- [ ] **PASS** — all blocking items satisfied → deliver the profile.
- [ ] **VETO** — list findings, assign remediation, require re-review.

> A behavioral profile is a tool for working better with people — never a tool for deciding about them.
