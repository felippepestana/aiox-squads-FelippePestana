# Anti-Stereotype Guardrails

The rules that keep behavioral profiling ethical and useful. Enforced by `ethics-gate`.

## 1. Tendencies, not types
- ✅ "tends to", "leans", "in this sample", "with medium confidence"
- ❌ "this type always", "D people are", "she is an X so she will"

## 2. Context, weight 0
- A profile informs **how to work with** someone — never **whether** to hire, promote or pay them.
- Selection/promotion decisions use **evidence of performance** (see `talent-compass`, `performa`).

## 3. Consent and privacy
- Profile only with **informed consent**. Treat behavioral data as sensitive.
- Never reuse a profile outside its stated purpose; never share it without authorization.

## 4. No clinical claims
- This is not a diagnosis. Never imply mental-health conditions or use clinical labels.

## 5. Confidence honesty
- Small/indirect samples → **low confidence**, stated plainly.
- Don't manufacture certainty the evidence doesn't support.

## 6. No protected-attribute proxies
- Style/trait reads must never become a proxy for age, gender, race, religion, disability, etc.

## 7. Disagreement is signal
- When lenses (DISC/Big Five/Enneagram) disagree, **surface the tension** — don't average it into false certainty.

> If any of these is violated, `ethics-gate` issues a VETO and the profile does not ship until remediated.
