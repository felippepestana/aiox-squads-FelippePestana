# Enneagram Model (development lens — weight 0, consent-based)

The Enneagram is used **only as a developmental lens** — for self-awareness, coaching and onboarding, with consent. It has **low predictive validity for selection** and must never screen, score or rank anyone. Weight 0, always.

## The nine types (developmental sketch)

| Type | Core motivation | Growth edge |
|------|-----------------|-------------|
| 1 — Reformer | Integrity, correctness | Ease self-criticism; accept "good enough" |
| 2 — Helper | Being needed, connection | Own and voice their own needs |
| 3 — Achiever | Success, value via results | Authentic self vs. performed image; slow down |
| 4 — Individualist | Identity, authenticity | Stability; not over-identifying with feelings |
| 5 — Investigator | Competence, understanding | Engage and share before fully "ready" |
| 6 — Loyalist | Security, certainty | Trust own judgment; manage anticipatory anxiety |
| 7 — Enthusiast | Stimulation, options | Focus and follow-through; sit with discomfort |
| 8 — Challenger | Control, protection | Vulnerability; temper intensity |
| 9 — Peacemaker | Harmony, comfort | Assert priorities; avoid conflict-avoidance |

## Reading guidance
- Use the person's **self-reported** type; never assign a type from outside as fact.
- Frame everything as growth and self-awareness, not assessment.
- Always state the instrument's limits.

> Every Enneagram output carries: *"A development lens, shared with consent — weight 0 in any people decision."*
