# Task: Diagnóstico e Reconstrução do Portal da Transparência

**ID:** `pd-diagnosticar-transparencia`
**Executor:** `arquiteto-transparencia`
**Tier:** Tier 1
**Use Cases:** UC-PD-009

## Overview
Diagnostica a conformidade do Portal da Transparência e especifica sua reconstrução (dados abertos/API, dashboards, acessibilidade, linguagem cidadã).

## Input
- URL do portal atual e escopo do diagnóstico

## Output
- Diagnóstico + checklist de conformidade + especificação de reconstrução (template spec-painel-transparencia-tmpl.md), salvo em output/transparencia/

## Action Items
1. Levante os módulos existentes e a atualização dos dados
2. Aplique o checklist (LAI/LC131/SIAFIC/PNTP/EBT/WCAG) — ver data/criterios-transparencia.md
3. Compare com cases de referência (Niterói, Sobral, São Paulo)
4. Aponte lacunas e priorize correções
5. Especifique API (OpenAPI), dados abertos, dashboards, WCAG e linguagem cidadã
6. Observe LGPD na transparência ativa

## Acceptance Criteria
- [ ] Diagnóstico com lacunas identificadas
- [ ] Checklist de conformidade aplicado
- [ ] Especificação de reconstrução acionável
- [ ] Arquivo salvo via Write
